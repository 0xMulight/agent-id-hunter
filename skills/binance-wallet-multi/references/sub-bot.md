# 钱包 Bot 交接

只有宿主实际支持持久创建 Bot 时才执行创建。一次性子代理、新聊天窗口或复制的提示词，不会自动继承已登录的钱包。

创建前检查：

- 能否运行同一套 Python / Node / baw，并访问同一份私有 profiles.json 与钱包目录。
- 是否为同一 OS 用户、同一持久运行环境；能访问共享工作区不等于能访问私有 home 或钥匙串。
- 能否使用同一个 runtime.lock 串行调用。主 Bot 交接任务，由钱包 Bot 执行，避免两边直接并发配对或交易。

同环境且权限满足时，一个钱包 Bot 管理全部编号。不能共享同一私有环境时，在目标环境重新建立配置和配对，绝不把 session.json、实例 ID、token 或二维码写进交接文档。

可复制的交接内容：

> 你负责用户的币安 Agentic Wallet 编号管理。先读取已安装的 binance-wallet-multi/SKILL.md。通过绝对路径调用 wallet_profiles.py，按用户指定的编号查询，不依赖其他 Bot 的聊天记忆。启动后先运行 doctor、list 和 check，无法访问私有运行配置就报告缺少什么，不新建一份假配置冒充接管成功。钱包编号和用户确认的公开地址另附。默认仅查询；任何 Mint、转账、兑换、授权和签名都须展示具体钱包与预览，再取得该笔明确确认。不输出凭证、实例 ID 或会话文件，不自动登出、清理目录或轮换实例 ID。任务结束只交回编号、公开地址、结果与待处理项。

交接可填写脚本绝对路径、私有配置路径引用、编号与经用户确认的公开地址。不要填写配置内容或登录链接。在钱包 Bot 自己的新命令进程中重复只读核验；未核验之前只称“交接已准备”。
